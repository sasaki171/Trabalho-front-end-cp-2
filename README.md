# Conecta Campus

Site estático que apresenta os espaços e serviços de um campus universitário. O objetivo é ajudar alunos e visitantes a encontrar locais do campus e saber o que cada um oferece.

Projeto desenvolvido para o Checkpoint 2 da turma 1TDSPB.

## Páginas

- **Início** (`index.html`): apresentação do projeto e destaque de alguns locais
- **Locais** (`locais.html`): lista dos locais com categoria, localização e informações úteis
- **Detalhes** (`detalhes.html`): informações completas de um local, incluindo serviços e acessibilidade
- **Integrantes** (`integrantes.html`): apresentação dos integrantes do grupo
